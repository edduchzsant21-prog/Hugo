# Detector de Ruptura

Herramienta para detectar puntos de ruptura en sistemas financieros utilizando análisis de entropía y medidas de orden fractal.

## Descripción
Este proyecto forma parte de las herramientas desarrolladas para evaluar sistemas financieros mediante conceptos de entropía como medida de orden fractal.

## Características
- Análisis de ruptura en series temporales
- Cálculo de entropía
- Medidas fractales
- Evaluación de sistemas financieros
